九州 山歩きメモ

コースの線は OpenStreetMap のデータから作った下書きです。現地の標識と公的な情報で必ず確認してください。予定と状態は、この端末に保存されます。

九州の山を歩くための、計画・地図・記録のアプリです。山に行く前と、歩いている間に使います。

1. 使い始める
  • URLを開くだけで使えます。ログインや登録は要りません。
  • ホーム画面に追加すると、アプリのように使えて、記録も消えにくくなります。
    iPhone: Safari または Chrome で開いて、共有ボタン(またはメニュー) → 「ホーム画面に追加」。
    Android: Chrome で開いて、メニュー → 「ホーム画面に追加」または「アプリをインストール」。
  • 画面の下のタブで切り替えます。コース(山の一覧)、計画(天気・持ち物)、地図(現在地)、記録(写真と文章)。
2. 山に行く前に
  • 地図を保存します。「地図」タブの「この範囲の地図を保存」を、Wi-Fi のある場所で押してください。山は圏外になることが多く、保存しておけば、機内モードでも地図が見えます。
  • 「計画」タブで、日付と出発時刻を入れると、日没の時刻、下山を終える目標、折り返す時刻の目安が出ます。
  • 天気は、画面に出た予報に加えて、気象庁の予報も見てください。山の天気は急に変わります。
  • 持ち物は、チェックしながら準備できます。内容は、季節と山の高さで変わります。
  • 行き先と、下山の予定時刻を、家族や友人に伝えておいてください。
3. 山の中で
  • 「地図」タブの「現在地」を押すと、自分の位置が出ます。位置は、あなたのスマホのGPSで調べていて、他の人には見えません。
  • 赤い線が、コースの目安です。ルートから約50m離れると、警告が出ます。道に迷ったかもしれないと思ったら、来た道を戻って、標識を確認してください。
  • 寒いと、スマホの電池が早く減ります。モバイルバッテリーと、機内モードの利用がおすすめです。
  • 圏外でも、GPSは使えます。保存した地図が表示されます。
  • けがや遭難など、困ったときは、画面右上の赤い「緊急」ボタンを、約1秒、長押ししてください。(ポケットの中での押し間違いを防ぐため、短く触れただけでは開きません。)現在地の緯度経度と住所、119番・110番に電話するボタン、電話での伝え方が出ます。位置は、メッセージで家族や同行者に送れます。出発前に、一度開いて、目を通しておいてください。
4. 歩いた軌跡を記録する
  • 「地図」タブの「軌跡の記録を始める」を押すと、歩いた道をGPSで残します。終わったら「記録を終了して保存」を押します。
  • 記録中は、画面をつけたままにしてください。画面が消えると、記録が途切れることがあります。
  • 軌跡は、コースの赤い線とは別に保存されます。迷って歩いた道が、次回の目安にならないようにするためです。
5. 記録(写真と文章)
  • 「記録」タブで、日付、山、ひとこと、写真(10枚まで)を残せます。
  • 記録と写真は、あなたのスマホの中だけに保存されます。サーバーには送られません。他の人には見えず、作った人(アプリの管理者)にも見えません。
  • そのため、スマホを買い替えたり、ブラウザのデータを消したりすると、記録は消えます。大切な記録は、ときどき「書き出し」でファイルに保存してください。新しいスマホでは、「読み込み」で戻せます。
  • iPhone では、Safari でも Chrome でも、保存したデータが消えることがあります(iPhone の Chrome は、中身が Safari と同じ仕組みのためです)。ホーム画面のアイコンから開いて使い、「記録」タブの上に出る、書き出しの案内に従って、ときどきバックアップを取ってください。
  • 同じスマホを複数人で使うと、記録が混ざります。
6. 通信と、プライバシー
  • あなたの位置、写真、記録を、このアプリのサーバーに送ることはありません。
  • アプリを使うと、次の通信が行われます。
    ・地図の画像: 国土地理院のサーバー
    ・天気の予報: Open-Meteo(場所と日付を送ります)
    ・アプリ本体: GitHub Pages
7. 安全のために(必ず読んでください)
  • ルートの線は、自動で作った下書きです。現地の登山道と、数十mずれていたり、通れない道が入っていたりすることがあります。現地の標識と、見える道を優先してください。
  • 時間の目安は、休憩を含まず、初心者の場合は目安の1.3倍ぐらいかかります。余裕を持って計画してください。
  • 日没の時刻は計算値です。山や谷の陰では、もっと早く暗くなります。ヘッドライトを持ってください。
  • 天気の判定は、目安です。雨、風、雷の気配があるときは、引き返してください。無理をしないことが、一番大切です。
  • アプリは、紙の地図、コンパス、ヘッドライト、防寒具の代わりにはなりません。電池が切れたり、壊れたりすることもあります。
  • 困ったとき、命に関わるときは、迷わず 119 番(救急・救助)に連絡してください。つながらないときは、電波の届く場所まで移動します。
  • このアプリを使った結果について、作った人は責任を負えません。自分の判断で、安全に楽しんでください。

電話での伝え方

  1. 落ち着いて、安全な場所にいるかを確かめます。崖や落石の危険があるときは、無理に動かず、そのままで電話します。
  2. 電話をかけて、最初に、「山で、けが(または道に迷った)です」と言います。
  3. 次の順に伝えます。
    • 場所: 山の名前、上の「住所」と「緯度経度」、近くの目印(標識・分岐・施設)
    • 人数と、けがの様子(意識があるか、歩けるか、出血や痛み)
    • 自分の携帯電話の番号(折り返しのため)
    • 持っているもの(水、食料、防寒具、ライト)
  4. 電話は、相手が切るまで切りません。折り返しを受けられるよう、電源とマナーモードの解除を確かめ、画面を暗くして電池を節約します。
  5. 家族や同行者にも、上の「位置を共有する」で、場所を知らせます。

電話がつながらないとき

  • 圏外でも、緊急通報(110・119・118)は、他の通信会社の電波があれば、つながることがあります。まず発信してみます。
  • 安全な範囲で、尾根や見晴らしのよい場所など、電波の届きやすい所へ移ります。同行者がいれば、1人が電波のある所へ行きます。
  • 圏外でも、位置の緯度経度は、GPSで出せます。画面のスクリーンショットを撮り、電波が戻ったら、すぐ伝えます。
  • 通信できないと、住所は出ません。緯度経度と、近くの目印を伝えてください。

助けを待つ間

  • 動けないときは、むやみに動かず、目立つ場所で待ちます。
  • 笛は、1分間に6回(約10秒おき)吹いて、1分休みます。夜は、ライトを同じように点滅させます。
  • レインウェア、防寒着、ビニール袋などで、体温を守ります。水と食料は、少しずつ取ります。
  • 電波が全くないときは、機内モードで電池を節約し、決めた時間(例: 15分ごと)だけ解除して、発信を試します。

この画面は、いざというときに迷わないよう、出発前に一度、目を通しておいてください。位置は、スマホのGPSで調べた目安で、数十mずれることがあります。
